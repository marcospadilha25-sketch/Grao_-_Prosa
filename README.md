# Gr-o-Prosa
O Grão &amp; Prosa é um café de bairro feito para quem busca uma pausa na rotina acelerada. Longe de ser apenas um lugar de passagem rápida, o espaço foi desenhado para abraçar o cliente: mesas de madeira de demolição, luz quente e amarelada, cheiro de bolo caseiro saindo do forno e trilha sonora suave (MPB e Jazz instrumental).
